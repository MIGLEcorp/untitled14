# MBrowser 4.4.0 — CEF-only migration preview

**Состояние:** экспериментальная сборка для проверки миграции. Не заменяет проверенный стабильный релиз 4.3.0 автоматически.

## Без WebView2

- Основной проект удалил ссылку на пакет Microsoft.Web.WebView2, исключил старые WebView2-классы из компиляции и не загружает WebView2 при запуске.
- Движок всех основных вкладок — кастомный Chromium Embedded Framework 154 с соответствующими V8/GPU/locale ресурсами.
- `--webview2` больше не включает старый движок. Установщик не распространяет и не устанавливает Microsoft Edge WebView2 Runtime.
- Отдельный необязательный WebKit/Playwright helper — не WebView2, остаётся инструментом предварительного просмотра.

## Функции, перенесённые на CEF

- Открытие вкладок, переходы, история, активные и спящие вкладки, безопасная выгрузка без несохранённых форм и медиа, восстановление позиции прокрутки.
- Загрузки: диалог выбора файла, индикатор, список загрузок.
- Разрешения камеры/микрофона и другие поддерживаемые Chromium запросы: запрос внутри браузера, запоминание разрешений по origin, управление списком.
- Автозаполнение: собственный `CefSharp.PostMessage` мост к существующему шифрованному хранилищу, проверка происхождения страницы и безопасного поля входа.
- Импорт cookie через нативный CEF CookieManager, поддержка partition key посредством DevTools с явным сообщением об ошибках импорта.
- Manifest V3: копирование распакованных расширений, включение при запуске CEF, `content_scripts`, service worker, `chrome.storage`, chrome.runtime messaging, страницы popup/options в интерфейсе браузера.
- Перевод страницы через Google Translate (адрес передаётся внешнему сервису только после нажатия пользователя), установка пакета Immersive Translate для Chromium, перевод текста изображения через CEF DevTools screenshot + OCR.
- Закладки, профили, настройки, темы, импорт данных, дефолтный браузер, меню, поиск, GPU/RAM диагностика сохраняются.

## Проверено

- 37 внутренних unit/integration проверок, включая ленту вкладок, защищённый профиль, cookie-данные, пароли, расширения и хранение состояний.
- Нативный рендерер CEF на локальном HTTP сайте и JavaScript-агент.
- Манифест V3 на изолированном профиле: content script, service worker, chrome.storage, runtime.sendMessage, открытие popup по chrome-extension://.
- Отсутствие WebView2 в зависимостях основной сборки проверяется отдельно перед публикацией.

## Ограничения и риски

- Нельзя утверждать полный паритет со всеми Chrome Extension APIs, CRX/Web Store или всей функциональностью Immersive Translate только по трём тестам MV3.
- Реальное автозаполнение, разрешения на произвольных сайтах, загрузка больших файлов, импорт всех типов partitioned cookie и OCR-перевод всех изображений требуют расширенных сценарных тестов.
- Экспериментальные оптимизации RAM/VRAM не гарантируют снижения потребления памяти. Никакой перенос JavaScript-кучи на диск не реализован.
- Перед реальным обновлением следует сохранить данные пользователя. Изолированные тесты используют отдельный профиль в %TEMP%.

## Как тестировать

Загрузить `MBrowser-4.4.0-cef-only-candidate-Setup-x64.exe` из соответствующего предварительного релиза, **закрыть браузер** перед установкой. Для безопасной проверки без замены установленной версии используйте тестовую установку в отдельную папку (`/TESTMODE=1`, `/DIR="..."`).
