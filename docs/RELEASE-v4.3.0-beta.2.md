# MBrowser 4.3.0-beta.2 — Custom CEF 154

В этом предварительном выпуске MBrowser использует **локально собранный Chromium Embedded Framework 154** (Chromium 154.0.8037.98), а не только стандартный CEF из NuGet.

## Изменения

- Кастомная нативная сборка CEF с экспериментальной функцией `MBrowserCompactDecodedImageCache`. Управление доступно через настройки памяти; функция не обещает конкретного снижения RAM и не включается без соответствующей настройки.
- Исправлена упаковка: `libcef.dll` поставляется **вместе с ресурсами из той же сборки** — V8 snapshot, `resources.pak`, GPU-библиотеками и локализациями. Смешивание ресурсов разных CEF приводило к проблемам JavaScript.
- Улучшено повторное применение настроек активной страницы после загрузки главного фрейма.
- Для CEF smoke-теста используется изолированный HTTP-сервер на `127.0.0.1`, а не внешний сайт. Тест не использует основной профиль или установленный браузер.
- Сохранён резервный запуск через `MBrowser.exe --webview2`.

## Проверка

Проверяются 33 внутренних теста, инициализация CEF, загрузка локальной страницы и наличие JavaScript-агента управления памятью. Установщик собирается только с комплектом нативных ресурсов.

**Ограничения:** режим экспериментальный. Нельзя считать загрузку агента гарантией снижения потребления памяти на всех сайтах. Нативное перемещение DOM/JavaScript-кучи в файл подкачки браузер не реализует.

## Установка

Скачайте `MBrowser-4.3.0-beta.2-Setup-x64.exe` в этом релизе. Перед обновлением закройте уже открытый MBrowser. Для проверки файла сравните SHA-256 с `MBrowser-4.3.0-beta.2-Setup-x64.sha256`.
