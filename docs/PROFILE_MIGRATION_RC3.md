# Перенос профиля FeatherBrowser → MBrowser (RC3)

При первом обычном запуске после обновления MBrowser переносит старые данные из:

- Источник: `%LOCALAPPDATA%\FeatherBrowser`
- Новый профиль: `%LOCALAPPDATA%\MBrowser`

**Перед переносом закройте предыдущую версию MBrowser.** Обе версии используют один mutex, поэтому перенос не запускается одновременно с открытым старым браузером.

## Что переносится

- `bookmarks.json` — закладки
- `session.json` — открытые вкладки и история навигации
- `passwords.dpapi` — зашифрованный менеджер паролей MBrowser; расшифровывается только той же учётной записью Windows
- `theme.json`, `preferences.json`, `Favicons`, `Extensions` и остальные файлы и каталоги профиля
- Папка `WebView2` переносится в `MBrowser\LegacyWebView2`, сохраняя исходную базу Chromium целиком; старые cookies и логины браузерного движка **не становятся автоматически активными** в CEF
- Распакованные расширения Manifest V3 из `Extensions` дополнительно регистрируются для CEF; невалидные пакеты сохраняются как файлы, но не включаются

## Безопасность

1. Перед началом MBrowser занимает общий mutex, исключающий одновременное использование профиля двумя версиями.
2. Копирует старый профиль в отдельную временную папку рядом с `MBrowser`, не изменяя источник.
3. Проверяет размер и SHA-256 каждого скопированного файла, а также общее количество файлов источника.
4. Создаёт отметку миграции и переименовывает проверенную копию в `MBrowser`.
5. Только после этого пытается удалить `FeatherBrowser`. Если удаление не удаётся, новая версия использует `MBrowser`, а старый каталог остаётся доступен.

При ошибке копирования или проверок новый профиль не вводится в эксплуатацию, исходные данные не удаляются, и приложение продолжает пользоваться старым профилем.

## Важно

Это перенос личных данных MBrowser и сохранение оригинала WebView2, **не полноценная конвертация** зашифрованной базы Edge/WebView2 в CEF. После перехода некоторые сайты могут потребовать повторный вход. Нативные пароли Edge не копируются в менеджер MBrowser как готовые записи; для них доступен ручной импорт CSV. Не удаляйте архив `LegacyWebView2`, пока не убедитесь, что нужные авторизации восстановлены.

Если `%LOCALAPPDATA%\MBrowser` уже существует без отметки миграции, операция отказывается перезаписывать его и сообщает о конфликте. Удалять какой-либо профиль вручную в таком случае не следует.

В каталоге установки старые компоненты и ярлыки Feather удаляются установщиком, а пустая папка `Feather` удаляется только если не содержит пользовательских файлов.
