# MBrowser 4.3.0 — Stable

Первый стабильный пакет серии 4.3 для Windows x64: оболочка MBrowser на .NET 10 и встроенный кастомный Chromium Embedded Framework 154.

## Что исправлено

- **Вкладки и изменение размера окна.** При расширении окна, когда все вкладки снова помещаются, лента автоматически сбрасывает прежний индекс прокрутки: стрелки исчезают, и скрытые прежде вкладки вновь отображаются. При сужении прокрутка возвращается; после закрытия вкладок оставшиеся не теряются.
- Добавлены автоматические проверки геометрии и фактической отрисовки ленты с 20 вкладками, многократного изменения ширины и закрытия вкладок.
- Комплект кастомного CEF теперь поставляется с соответствующими ресурсами, локализациями и V8 snapshot одной сборки. Смешивание нативной DLL и ресурсов из другого пакета ранее мешало инициализации JavaScript.
- Сохранены встроенная система памяти, переключатели экспериментальных политик CEF, диагностика RAM, WebView2 как резервный движок.

## Проверки перед релизом

- Регрессионный self-test: 35 тестов, 0 ошибок (включая новую отрисовку вкладок).
- Контроль SHA-256 ключевых нативных файлов в изолированном установщике.
- Изолированный запуск CEF на локальной странице с проверкой инициализации рендерера и JavaScript-агента.
- Установка из полного пакета в отдельную папку без изменения существующего установленного браузера.

## Известные ограничения

Обозначение Stable относится к проверенной сборке, а **не означает полного паритета CEF с WebView2**. Менеджер паролей, некоторые расширения, переводчик и часть разрешений сайтов по-прежнему доступны только при запуске `MBrowser.exe --webview2`. Экспериментальные оптимизации RAM/VRAM отключены по умолчанию и не гарантируют уменьшения памяти на любых сайтах. Не реализовано перемещение DOM/JS-кучи в дисковую память.

## Установка

Скачайте `MBrowser-4.3.0-Setup-x64.exe`. Закройте уже открытый MBrowser перед обновлением. Данные профиля `%LOCALAPPDATA%\FeatherBrowser` не удаляются. Для проверки скачанного файла используйте SHA-256 из `MBrowser-4.3.0-Setup-x64.sha256`.
