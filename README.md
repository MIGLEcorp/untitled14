# Feather

Небольшой браузер для Windows x64 на C# / .NET 10 и установленном Microsoft Edge WebView2. Интерфейс на русском, вкладки, поиск из адресной строки, история назад/вперёд, загрузки файлов и восстановление сессии.

## Запуск

Откройте **`dist\Feather.exe`** или **`start.cmd`**. Переносить нужно всю папку `dist`, а не один exe.

На этой машине уже установлены .NET Desktop Runtime 10 и WebView2 Runtime. Для другой машины нужны [Desktop Runtime .NET 10](https://dotnet.microsoft.com/download/dotnet/10.0) и [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Как экономится память

- Только одна вкладка содержит настоящий WebView2. При переключении прежний контрол уничтожается; в фоне остаются адрес, название и история, до 80 адресов на вкладку.
- Стартовая страница нарисована средствами Windows Forms. При холодном запуске на главную Chromium вообще не запускается.
- При сворачивании приложение запрашивает у WebView2 режим `MemoryUsageTargetLevel.Low`, при восстановлении возвращает `Normal`.
- Сессия восстанавливает только выбранную страницу. Остальные вкладки открываются по требованию. Максимум — 100 вкладок.
- Общий профиль движка, без Electron, расширений, фоновых превью и отдельного движка на каждую вкладку.

**Цена экономии:** при смене вкладки страница загружается заново. Несохранённый ввод, DOM/JS-состояние и позиция прокрутки не сохраняются; видео прекращается. Файлы лучше скачивать, оставив вкладку открытой до завершения. Cookies и авторизация сохраняются в профиле. История хранит URL: возврат на страницу не повторяет POST-запрос и не восстанавливает отправленную форму. Приложение поддерживает web-адреса HTTP/HTTPS; локальные файлы и запуск внешних приложений через специальные схемы не поддерживаются.

Это браузерная оболочка над современным движком, а не собственная реализация HTML/JavaScript. Для тяжёлого сайта нельзя гарантировать фиксированный предел в МБ. Даже одна страница запускает несколько служебных процессов движка; закрытие контрола не означает их мгновенного завершения. Механизм соответствует [рекомендациям WebView2 по производительности](https://learn.microsoft.com/microsoft-edge/webview2/concepts/performance) и [документации режима памяти](https://learn.microsoft.com/dotnet/api/microsoft.web.webview2.core.corewebview2.memoryusagetargetlevel).

Счётчик внизу показывает сумму рабочих наборов приложения и процессов **его** WebView2-профиля. Общие страницы памяти могут учитываться повторно, crashpad не входит в API списка процессов. Это приблизительный замер физической памяти, не лимит. Наведите указатель на счётчик, чтобы увидеть private commit и число процессов. Private commit не равен физической оперативной памяти.

## Управление

| Клавиши | Действие |
| --- | --- |
| Ctrl+L / Alt+D | Адресная строка |
| Ctrl+T | Новая вкладка |
| Ctrl+W / средняя кнопка мыши по вкладке | Закрыть вкладку |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка |
| Alt+← / Alt+→ | Назад / вперёд |
| Alt+Home | Стартовая страница, выгрузить сайт |
| F5 / Ctrl+R | Обновить / остановить загрузку |
| Ctrl+J | Загрузки текущей страницы |

Поисковые запросы отправляются в Google. Адреса без схемы открываются через HTTPS; `localhost` и loopback — через HTTP. Другую поисковую систему можно открыть как обычный сайт.

## Профиль

`%LOCALAPPDATA%\FeatherBrowser\`

- `session.json` — вкладки и история; запись через временный файл.
- `WebView2\` — cookies, cache и данные сайтов.
- `errors.log` — ошибки, если они возникнут.

Можно запустить один экземпляр на пользователя. Профиль не импортируется из Edge или других браузеров. Это не приватный режим: адреса записываются на диск в сессию.

## Сборка и проверка

```powershell
dotnet build .\Feather.csproj -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

Используется установленный SDK WebView2 `1.0.3179.45`, движок — системный Evergreen Runtime. Сборка framework-dependent: не копирует .NET и Chromium в дистрибутив. WPF-зависимость пакета исключена, поскольку интерфейс использует Windows Forms.

`--self-test` проверяет адреса, историю, запись/восстановление сессии и повреждённые данные. `--smoke-test` запускает настоящее окно и WebView2 с отдельным временным профилем и локальным HTTP-сервером: JavaScript, переходы, назад/вперёд, закрытие, 20 спящих вкладок и быстрые переключения. Внешние сайты для этой проверки не используются. Результат и замеры памяти сохраняются в `smoke-results.json`, изображение главной — в `preview.png`. Тестовый профиль остаётся в `%TEMP%\Feather-smoke-*` для диагностики и не меняет обычный профиль.

Исходники: `MainForm.cs` — окно и жизненный цикл движка; `BrowserChrome.cs` — интерфейс; `BrowserState.cs` — адреса, вкладки и сессия; `CoreTests.cs` / `SmokeTests.cs` — проверки.
